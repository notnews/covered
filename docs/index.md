# covered

`covered` measures whose voices occupy the news — at scale, across a
quarter-century of CNN transcripts — using the Herfindahl-Hirschman Index
(HHI), the standard measure of market concentration, applied to on-air
speakers and cited sources.

See the [README](https://github.com/notnews/covered) for the full pipeline
description, data sources, and CLI usage.
